# Handoff WP-01 — esqueleto isolado

Você está implementando um pacote estritamente limitado do P0 do projeto IDEIA.

## Objetivo

Criar a menor base executável e testável para p0.

## Leia antes de editar

- docs/implementation/adr/ADR-001-runtime-p0.md
- docs/implementation/adr/ADR-002-isolamento-codigo-legado.md

## Arquivos autorizados

- p0/package.json
- p0/tsconfig.json
- p0/.gitignore
- p0/src/index.ts
- p0/test/smoke.test.ts
- p0/README.md

## Implemente

- package ESM privado;
- engines restrito à linha Node 24;
- script que execute exatamente o smoke test com node:test;
- configuração TypeScript aderente à ADR-001;
- export mínimo importado pelo smoke test;
- README com runtime requerido, comando e limitação de typecheck.

## Critérios de aceite

- nenhuma dependência;
- node --test test/smoke.test.ts executa com sucesso a partir de p0;
- import local usa extensão .ts;
- nenhum arquivo de packages é importado;
- não declarar que houve typecheck.

## Regras

- A árvore packages é legado em quarentena: não edite nem importe nada dela.
- Não edite documentos normativos.
- Não acesse a rede e não adicione dependências.
- Não altere arquivos fora da lista autorizada.
- Use Node ESM e TypeScript compatível com remoção nativa de tipos.
- Não use any, ts-ignore, catch vazio, fallback permissivo ou TODO.
- Não invente campos ou componentes adicionais.
- Se houver conflito ou arquivo necessário fora do escopo, pare sem editar e relate.

## Resposta obrigatória

1. resumo;
2. arquivos alterados;
3. testes executados e resultado;
4. requisitos atendidos;
5. limitações;
6. confirmação de que não editou fora do escopo.
