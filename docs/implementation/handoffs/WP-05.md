## Dependência autorizada

Somente ajv 8.20.0, exata, em dependencies. Gere o lockfile com scripts de instalação desabilitados. Se a versão exata não estiver disponível, pare; não troque a versão.

## Implemente

- compilador Ajv específico para draft 2020-12;
- configuração strict true, coerceTypes false, useDefaults false, removeAdditional false, validateFormats false e $data false;
- preload de todos os schemas locais antes de compilar;
- zero loadSchema, fetch, import remoto ou URI dinâmica;
- geração standalone ESM determinística;
- declaração TypeScript gerada com unknown e resultado boolean, sem any;
- registry fechado contract → validator;
- validateContract que retorna valor validado ou erro de domínio redigido;
- scripts package para gerar, conferir drift e testar.

## Critérios de aceite

- npm ci com scripts desabilitados funciona em cópia limpa;
- todos os schemas passam meta-validação e strict mode sem warning;
- geração repetida produz bytes idênticos;
- runtime de validate.ts não inicializa/compila Ajv; imports gerados ficam limitados a helpers de ajv/dist/runtime;
- contract desconhecido falha;
- campo desconhecido, required ausente, tipo incorreto e /2 falham;
- nenhum validator faz coerção, default ou remoção;
- tentativa de schema URI fora do catálogo falha sem rede;
- npm ci --omit=dev executa os validators com sucesso;
- o build não afirma validar invariantes transacionais ou semânticos.

## Regras

- Não edite packages nem docs.
- Não acrescente ajv-formats, ajv-cli ou outra dependência.
- Não use npx.
- Não habilite $data, keyword customizada ou schema fornecido pelo usuário.
- Não edite manualmente validators.generated.js depois da geração.
- Não use any, ts-ignore, catch vazio, fallback permissivo ou TODO.
- Se o output standalone não puder ser ESM reproduzível, pare e relate.
