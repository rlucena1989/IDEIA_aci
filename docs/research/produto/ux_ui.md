# UX/UI para IDE com IA

| Elemento | Importância | Referências | MVP | Risco |
|---|---|---|---|---|
| Chat lateral | entrada natural | Cursor/Cline | Sim | prompt ambíguo |
| Agent mode | tarefas multi-etapa | Devin/Cline | Sim CLI/UI simples | autonomia excessiva |
| Pair programming | feedback rápido | Cursor | Sim | interrupção |
| Background task | tarefas longas | Devin | Versão 1 | custo invisível |
| Painel de plano | revisão antes da ação | Cline | Sim | falsa confiança |
| Execução/timeline | acompanhar ações | Devin | Sim | excesso de detalhe |
| Diff/aprovação | controle humano | todas | Sim | aprovação cega |
| Custo/confiança | decisão informada | oportunidade | Sim básico | métrica enganosa |
| Histórico/replay | aprendizado/auditoria | IDEIA | Versão 1 | privacidade |
| Rollback | segurança | Git/checkpoints | Sim | perda não relacionada |
| Quick commands/templates | produtividade | IDEs | Sim | configuração complexa |
| Cockpit multiagente | frotas | Devin Desktop | Versão 2 | complexidade |

Princípio: mostrar intenção, evidência, risco, diff e próximo passo; esconder raciocínio privado não verificável. Sempre permitir cancelar.
