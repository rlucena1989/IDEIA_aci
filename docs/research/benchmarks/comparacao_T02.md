# Comparação T02 — OpenCode vs Freebuff

| Métrica | OpenCode | Freebuff |
|---|---:|---:|
| Status funcional | sucesso | sucesso |
| Testes finais | 5/5 | 5/5 |
| Aceite | 2/2 | 2/2 |
| Arquivos de código alterados | 1 | 1 |
| Alterações fora do código | não observadas | `.freebuff` metadata criada |
| Retries | 0 | 0 |
| Intervenção humana | 0 | 0 |
| Modelo/custo capturados | não | não |
| Instalação modificada | não | não |

## Conclusão
As duas ferramentas produziram uma correção funcional mínima em cópias isoladas. A comparação de custo, modelo, latência e qualidade semântica ainda é incompleta porque esses dados não foram capturados de forma equivalente.

## Próxima melhoria do protocolo
- registrar versão/modelo exibidos;
- capturar custo/créditos quando disponível;
- separar metadados da ferramenta do workspace de código;
- executar casos com mais complexidade que diferenciem planejamento, contexto e verificação.
