# Ferramentas adicionais relevantes

## OpenHands
- Categoria: agente open source para desenvolvimento.
- Repositório: https://github.com/All-Hands-AI/OpenHands
- Relevância: ambiente agentic, execução de ferramentas e benchmark de tarefas reais.
- Uso recomendado: estudar runtime, sandbox e avaliação; verificar licença/versão antes de adaptar.

## Aider
- Categoria: agente CLI open source.
- Site/repositório: https://aider.chat / https://github.com/Aider-AI/aider
- Relevância: fluxo terminal-first, Git, múltiplos modelos e edição incremental.
- Uso recomendado: referência de UX CLI e integração Git.

## Continue
- Categoria: IDE/CLI open source e framework de agentes.
- Site/repositório: https://www.continue.dev / https://github.com/continuedev/continue
- Relevância: modelos locais/cloud, configuração, extensão e agentes.
- Uso recomendado: estudar extensibilidade e configuração de providers.

## SWE-agent
- Categoria: agente de software para issues/benchmarks.
- Repositório: https://github.com/SWE-agent/SWE-agent
- Relevância: execução reprodutível em issues e avaliação SWE-bench.
- Uso recomendado: benchmark e desenho de ambiente de resolução.

## OpenHands SDK
- Categoria: SDK/runtime agentic.
- Relevância: embedding de agentes em aplicações e workflows.
- Uso recomendado: comparar abstração de runtime, tools e sandbox.

## LangGraph
- Categoria: framework de orquestração stateful.
- Site: https://langchain-ai.github.io/langgraph/
- Relevância: grafos, checkpointing, interrupções e human-in-the-loop.

## LiteLLM
- Categoria: gateway/adapter multi-provider.
- Site: https://docs.litellm.ai/
- Relevância: interface unificada, budgets, callbacks e fallback.

## OpenRouter
- Categoria: gateway SaaS de modelos.
- Site: https://openrouter.ai
- Relevância: catálogo e roteamento; avaliar privacidade, latência e lock-in.

## Model Context Protocol
- Categoria: protocolo de integração de tools/resources/prompts.
- Site: https://modelcontextprotocol.io
- Relevância: base para extensibilidade, com necessidade de policy e isolamento.

## GitHub Copilot / Replit Agent / JetBrains AI
- Categoria: produtos comerciais de assistência/agentes.
- Relevância: distribuição, integração nativa e padrões de UX.
- Limitação: detalhes internos, retenção e métricas dependem de planos/termos.

## Referências
Os sites e repositórios acima devem ser revalidados por versão, licença e data antes de decisões de implementação.
