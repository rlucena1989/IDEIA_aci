# Licenciamento de Outputs e Detecção de Similaridade

**Data:** 11 de agosto de 2026  
**Status:** Documentação de estratégia  
**Objetivo:** Definir estratégia de licenciamento de outputs e detecção de similaridade

## Visão geral

Licenciamento de outputs define os direitos de uso sobre código gerado por IA. Detecção de similaridade identifica código gerado por IA para atribuição e conformidade.

## Licenciamento de outputs

### 1. Licença MIT para outputs

**Rationale:**
- **Permissiva:** Permite uso comercial, modificação, redistribuição
- **Compatível:** Compatível com licenças de código existentes
- **Clara:** Fácil de entender e aplicar
- **Padrão:** Amplamente adotada na indústria

**Termos principais:**
- Permite uso comercial
- Permite modificação
- Permite redistribuição
- Requer atribuição (opcional para outputs de IA)
- Não requer copyleft

**Implementação:**

### 3. Licença personalizada para outputs

**Rationale:**
- **Customizável:** Permite termos específicos
- **Proteção:** Pode incluir cláusulas de proteção
- **Flexibilidade:** Adapta-se a requisitos específicos

**Implementação:**
```javascript
class CustomLicenseManager {
  generateLicenseHeader(output, terms) {
    const licenseTerms = terms || {
      commercialUse: true,
      modification: true,
      redistribution: true,
      attribution: false,
      copyleft: false
    };
    
    let licenseText = `// Generated by IDEIA AI
// Custom License
// Generated at: ${new Date().toISOString()}
//
// Terms:
`;
    
    if (licenseTerms.commercialUse) {
      licenseText += '// - Commercial use: permitted\n';
    }
    
    if (licenseTerms.modification) {
      licenseText += '// - Modification: permitted\n';
    }
    
    if (licenseTerms.redistribution) {
      licenseText += '// - Redistribution: permitted\n';
    }
    
    if (licenseTerms.attribution) {
      licenseText += '// - Attribution: required\n';
    }
    
    if (licenseTerms.copyleft) {
      licenseText += '// - Copyleft: required\n';
    }
    
    licenseText += `\n${output}`;
    
    return licenseText;
  }
  
  addLicenseHeader(file, output, terms) {
    const licensed = this.generateLicenseHeader(output, terms);
    fs.writeFileSync(file, licensed);
  }
}
```

## Detecção de similaridade

### 1. Detecção baseada em AST

**Implementação:**
```javascript
const { parse } = require('@babel/parser');
const traverse = require('@babel/traverse').default;
const generate = require('@babel/generator').default;

class ASTSimilarityDetector {
  calculateSimilarity(code1, code2) {
    const ast1 = parse(code1);
    const ast2 = parse(code2);
    
    const hash1 = this.hashAST(ast1);
    const hash2 = this.hashAST(ast2);
    
    return this.compareHashes(hash1, hash2);
  }
  
  hashAST(ast) {
    const hash = {};
    
    traverse(ast, {
      enter(path) {
        const nodeType = path.node.type;
        hash[nodeType] = (hash[nodeType] || 0) + 1;
      }
    });
    
    return hash;
  }
  
  compareHashes(hash1, hash2) {
    const allKeys = new Set([...Object.keys(hash1), ...Object.keys(hash2)]);
    
    let similarity = 0;
    let total = 0;
    
    for (const key of allKeys) {
      const count1 = hash1[key] || 0;
      const count2 = hash2[key] || 0;
      const max = Math.max(count1, count2);
      
      if (max > 0) {
        similarity += Math.min(count1, count2) / max;
        total++;
      }
    }
    
    return total > 0 ? similarity / total : 0;
  }
}
```

### 2. Detecção baseada em tokens

**Implementação:**
```javascript
class TokenSimilarityDetector {
  tokenize(code) {
    // Tokenizar código (simplificado)
    return code.split(/[\s\(\)\{\}\[\]\;\,\.\=]/g).filter(t => t.length > 0);
  }
  
  calculateSimilarity(code1, code2) {
    const tokens1 = this.tokenize(code1);
    const tokens2 = this.tokenize(code2);
    
    const set1 = new Set(tokens1);
    const set2 = new Set(tokens2);
    
    const intersection = new Set([...set1].filter(x => set2.has(x)));
    const union = new Set([...set1, ...set2]);
    
    return intersection.size / union.size;
  }
}
```

### 3. Detecção baseada em embeddings

**Implementação:**
```javascript
const { pipeline } = require('@xenova/transformers');

class EmbeddingSimilarityDetector {
  async calculateSimilarity(code1, code2) {
    const generator = await pipeline('feature-extraction', 'microsoft/codebert-base');
    
    const embedding1 = await generator(code1);
    const embedding2 = await generator(code2);
    
    return this.cosineSimilarity(embedding1, embedding2);
  }
  
  cosineSimilarity(vec1, vec2) {
    const dotProduct = vec1.reduce((sum, val, i) => sum + val * vec2[i], 0);
    const magnitude1 = Math.sqrt(vec1.reduce((sum, val) => sum + val * val, 0));
    const magnitude2 = Math.sqrt(vec2.reduce((sum, val) => sum + val * val, 0));
    
    return dotProduct / (magnitude1 * magnitude2);
  }
}
```

### 4. Detecção de plágio

**Implementação:**
```javascript
class PlagiarismDetector {
  constructor(similarityDetector) {
    this.similarityDetector = similarityDetector;
    this.threshold = 0.8;
  }
  
  detectPlagiarism(code, referenceCodes) {
    const results = [];
    
    for (const reference of referenceCodes) {
      const similarity = this.similarityDetector.calculateSimilarity(code, reference.code);
      
      if (similarity >= this.threshold) {
        results.push({
          reference: reference.source,
          similarity,
          isPlagiarism: true
        });
      } else {
        results.push({
          reference: reference.source,
          similarity,
          isPlagiarism: false
        });
      }
    }
    
    return results;
  }
}
```

## Atribuição de outputs

### 1. Atribuição automática

**Implementação:**

```javascript
class OutputAttributor {
  attributeOutput(output, metadata) {
    const attribution = {
      generatedBy: 'IDEIA AI',
      generatedAt: new Date().toISOString(),
      model: metadata.model,
      prompt: metadata.prompt,
      context: metadata.context,
      license: metadata.license || 'MIT'
    };
    
    return {
      output,
      attribution
    };
  }
  
  addAttributionComment(file, output, metadata) {
    const { output: code, attribution } = this.attributeOutput(output, metadata);
    
    const comment = `// ${JSON.stringify(attribution, null, 2)}\n\n${code}`;
    fs.writeFileSync(file, comment);
  }
}
```

## Conformidade com licenças

### 1. Verificação de licença

**Implementação:**
```javascript
class LicenseChecker {
  checkLicense(code, expectedLicense) {
    const licenseHeader = this.extractLicenseHeader(code);
    
    if (!licenseHeader) {
      return {
        hasLicense: false,
        isCompliant: false,
        reason: 'No license header found'
      };
    }
    
    const detectedLicense = this.detectLicense(licenseHeader);
    
    return {
      hasLicense: true,
      isCompliant: detectedLicense === expectedLicense,
      detectedLicense,
      expectedLicense
    };
  }
  
  extractLicenseHeader(code) {
    const lines = code.split('\n');
    const licenseLines = [];
    
    for (const line of lines) {
      if (line.startsWith('//') || line.startsWith('/*')) {
        licenseLines.push(line);
      } else {
        break;
      }
    }
    
    return licenseLines.join('\n');
  }
  
  detectLicense(licenseHeader) {
    if (licenseHeader.includes('MIT')) {
      return 'MIT';
    } else if (licenseHeader.includes('Apache')) {
      return 'Apache-2.0';
    } else if (licenseHeader.includes('GPL')) {
      return 'GPL';
    } else {
      return 'Unknown';
    }
  }
}
```

### 2. Validação de conformidade

**Implementação:**
```javascript
class ComplianceValidator {
  validateCompliance(codebase, expectedLicense) {
    const checker = new LicenseChecker();
    const results = [];
    
    for (const file of codebase.files) {
      const code = fs.readFileSync(file.path, 'utf8');
      const result = checker.checkLicense(code, expectedLicense);
      
      results.push({
        file: file.path,
        ...result
      });
    }
    
    return {
      totalFiles: results.length,
      compliantFiles: results.filter(r => r.isCompliant).length,
      nonCompliantFiles: results.filter(r => !r.isCompliant),
      results
    };
  }
}
```

## Recomendações

### Para licenciamento
- **Licença padrão:** MIT para outputs (simples e permissiva)
- **Licença enterprise:** Apache-2.0 (patent grant)
- **Licença customizada:** Para requisitos específicos
- **Atribuição automática:** Adicionar metadados de atribuição

### Para detecção de similaridade
- **AST-based:** Para detecção estrutural
- **Token-based:** Para detecção rápida
- **Embedding-based:** Para detecção semântica
- **Threshold:** 0.8 para detecção de plágio

### Para conformidade
- **Verificação automática:** Verificar licenças em CI/CD
- **Validação regular:** Validar conformidade periodicamente
- **Relatórios:** Gerar relatórios de conformidade
- **Alertas:** Notificar sobre não conformidade
