# Resumo executivo

A recomendação é construir uma plataforma local-first, modular e orientada a tarefas, começando por CLI + SDK. O MVP deve combinar planner, executor, filesystem, terminal sandbox, Git, diff, testes, rollback, aprovação humana, logs, budgets e um provider cloud com Ollama opcional.

## Descobertas
- Devin demonstra valor em tarefas longas e migrações, mas é proprietário.
- Cursor destaca UX, edição multi-arquivo e contexto.
- Cline destaca open source, Plan/Act, MCP e extensibilidade.
- IDEIA oferece referência local para multiagentes, políticas, auditoria e integração IDE.
- Trae foi confirmado apenas como produto ativo no site oficial; Kiro, FreeBuff, OpenCode, Antigravity e OmniRoute ainda precisam de identificação canônica.

## Oportunidades
Self-hosted, auditoria verificável, routing transparente, baixo custo, monorepos, legado e skills governadas.

## Riscos
Prompt injection, secrets, comandos destrutivos, supply chain, custo e contexto incorreto.

## Roadmap
MVP single-agent supervisionado; V1 RAG, extensão VS Code e workers; V2 multiagentes, self-hosted enterprise e MCP governado; futuro marketplace e aprendizagem de trajetórias.
