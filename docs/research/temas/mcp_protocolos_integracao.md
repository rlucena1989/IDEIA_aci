# MCP e protocolos de integração

> **Revisão de abordagem — 12/08/2026:** MCP foi movido para P1, começando por servidor local read-only, versão fixada e policy nativa. Discovery e descrições de tool são tratados como não confiáveis. Ver [RAT-17](../planejamento/revisao_abordagens_temas_2026-08-12.md#rat-17--mcp-e-protocolos-de-integração).

## 1. Descrição
MCP padroniza exposição de tools, resources e prompts para modelos/agentes.

## 2. Importância para a plataforma
Reduz custo de integração e cria ecossistema.

## 3. Ferramentas relacionadas
MCP SDKs, Cline, IDEIA, servidores de GitHub/Linear/Databases.

## 4. Abordagens existentes
Processo local/HTTP, schemas e capability discovery.

## 5. Grau de maturidade
Emergente/ativamente evoluindo.

## 6. Tecnologias recomendadas
SDK oficial, allowlist, autenticação, timeout e observabilidade.

## 7. Riscos e desafios
Servidor malicioso, tool poisoning e excesso de privilégios.

## 8. Oportunidades de inovação
Catálogo governado com score e políticas por tool.

## 9. Próximos passos
Integrar um servidor local read-only.

## 10. Referências
https://modelcontextprotocol.io/
