# Skills, plugins e ferramentas

> **Revisão de abordagem — 12/08/2026:** o baseline não tem marketplace. Duas integrações independentes devem provar repetição antes de SDK/registry; assinatura prova proveniência, não segurança do conteúdo. Ver [RAT-16](../planejamento/revisao_abordagens_temas_2026-08-12.md#rat-16--skills-plugins-e-ferramentas).

Extensões que adicionam instruções, tools e workflows.

## 2. Importância para a plataforma

MCP, SDK Cline, OpenVSX, VS Code extensions.

## 4. Abordagens existentes

## 5. Grau de maturidade
